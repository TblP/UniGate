# UniGate 1.0.9 — удобные обновления

В этом релизе обновления UniGate стали заметнее и удобнее на всех
поддерживаемых устройствах.

## ✨ Что улучшено

- При выходе новой версии в боковом меню появляется кнопка обновления.
- Windows самостоятельно скачивает проверенный установщик и запускает обновление.
- macOS и Android открывают официальную страницу нового релиза.
- Во время загрузки на Windows отображается прогресс.

## 🛡️ Надёжность

- Загруженные обновления Windows проверяются перед запуском установки.
- Адрес страницы релиза зафиксирован в приложении.
- Ошибка проверки сети не мешает обычной работе UniGate.

## 📦 Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; Play Protect или HyperOS могут показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
