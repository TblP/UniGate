# UniGate 1.0.5 — исправление AmneziaWG на macOS

### Что исправлено

- Исправлено подключение AmneziaWG на Mac в сетях без доступной IPv6-маршрутизации.
- UniGate больше не откатывает уже поднятый туннель, если сетевой сервис macOS (например USB‑Ethernet или док-станция) возвращает пустые настройки DNS/search domains.
- Исправление не затрагивает Windows, Android и остальные протоколы.

### Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; Play Protect или HyperOS могут показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
