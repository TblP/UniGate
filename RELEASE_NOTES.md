# UniGate 1.0.8 — обновление совместимости

Этот релиз улучшает совместимость настольных версий UniGate с новыми профилями
Amnezia и сохраняет поддержку профилей предыдущего поколения.

## ✨ Что улучшено

- Обновлён движок подключения Amnezia для Windows и macOS.
- Добавлена поддержка нового формата профилей Amnezia.
- Импорт и экспорт корректно сохраняют формат профиля.
- Сохранена обратная совместимость с ранее добавленными профилями.

## 🛡️ Надёжность

- Добавлены проверки совместимости при обработке новых настроек подключения.
- Улучшена подготовка компонентов перед сборкой приложения.
- Расширены автоматические тесты импорта и экспорта профилей.

## 📦 Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; Play Protect или HyperOS могут показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
