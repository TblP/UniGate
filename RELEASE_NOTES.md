# UniGate 1.0.6 — улучшение split-tunneling

В этом релизе мы сделали маршрутизацию точнее, а совместную работу
UniGate с другим VPN — предсказуемее и стабильнее.

## ✨ Что нового

- База GeoIP для RU-обхода теперь обновляется автоматически.
- Улучшена точность маршрутизации российских сайтов.
- Режим совместимости с другим VPN теперь автоматически учитывает его рабочие сети.
- UniGate остаётся основным VPN, а доступ к внутренним ресурсам второго VPN сохраняется.
- Уточнены описания настроек, чтобы поведение split-tunneling было понятнее.

## 🛡️ Надёжность

- Обновление GeoIP проверяется перед использованием.
- При проблемах с сетью UniGate продолжит работу с последней доступной базой.
- Добавлены дополнительные проверки генерации маршрутов и обновлений.

## 📦 Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; Play Protect или HyperOS могут показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
