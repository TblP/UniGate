# UniGate 1.1.6 — ядро sing-box 1.14

Сетевое ядро обновлено с 1.13.14 до 1.14.0 сразу на всех платформах: Windows, macOS и Android.

## Что нового

- sing-box 1.14.0 везде: sidecar на Windows и macOS, `libbox.aar` на Android.
- Генератор конфигурации приведён к схеме 1.14: убран устаревший `dns.independent_cache` — в новом ядре кэш DNS и так раздельный по серверу, а сама опция объявлена устаревшей.
- Все режимы конфигурации проверены `sing-box check` на новом ядре: proxy, TUN, обход LAN и RU, split по приложениям, а также outbound'ы Hysteria 2, VLESS+Reality, Trojan, TUIC и Shadowsocks.
- Android: клиент переведён на расширенные интерфейсы libbox 1.14, VPN-интерфейс теперь принимает от ядра список DNS-серверов вместо одного адреса.
- Вместе с ядром приезжают обновления апстрима: gVisor 20260727, quic-go 0.61, uTLS 1.8.7, NaiveProxy 150.
- `scripts/fetch-singbox.sh` (macOS/Linux) теперь сверяет версию уже скачанного ядра и перекачивает его при смене пина — раньше старый бинарник молча оставался на месте.

## Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; система может показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
