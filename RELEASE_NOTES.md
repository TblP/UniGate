# UniGate 1.1.1 — надёжнее обновление и подключение

Небольшой исправляющий релиз, повышающий стабильность приложения на Windows и macOS.

## Что исправлено

- Перед установкой обновления Windows корректно завершает фоновые компоненты UniGate.
- Установка не запускается, пока приложение не подтвердит безопасное завершение активного подключения.
- Улучшена устойчивость подключения на macOS при нестандартной конфигурации сетевых сервисов.
- Ошибки отдельных системных настроек больше не прерывают уже установленное подключение.

## Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; система может показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
