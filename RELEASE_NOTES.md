# UniGate 1.1.0 — стабильнее на macOS

Этот релиз улучшает надёжность подключения и работу приложения в разных
сетевых окружениях.

## ✨ Что улучшено

- Улучшено подключение на macOS при использовании внешних сетевых адаптеров.
- Настройка маршрутов теперь учитывает доступные возможности сети.
- Сетевые настройки корректнее обрабатываются при неполных системных ответах.
- Подготовлена стабильная цепочка последующих обновлений Android.

## 🛡️ Надёжность

- Ошибка отдельного сетевого сервиса больше не прерывает всё подключение.
- Неиспользуемые маршруты не мешают запуску туннеля.
- Сохранена совместимость с ранее добавленными профилями.
- Сборка Android теперь проверяет подпись перед публикацией.

## 📦 Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; Play Protect или HyperOS могут показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
> Переход Android на 1.1.0 требует однократной переустановки; последующие версии будут устанавливаться поверх.
