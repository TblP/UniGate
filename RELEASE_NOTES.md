# UniGate 1.2.0 — релизная подпись Android

Android-сборка больше не debug: APK собирается как release и подписывается отдельным релизным ключом. Это открывает публикацию в магазинах приложений — debug-пакеты там не принимают в принципе.

## ⚠️ Android: требуется переустановка

**Сертификат подписи сменился, поэтому обновить прошлую версию поверх не получится** — Android не принимает обновление, подписанное другим ключом.

Перед установкой удалите старую версию UniGate. Профили и настройки при удалении теряются, так что заранее выгрузите нужные профили через «Поделиться» либо сохраните ссылку подписки.

Это разовый переход: дальше обновления встают обычным образом.

## Что нового

- Android: сборка переведена на release-вариант с собственным релизным ключом; проверка подписи в CI сверяет отпечаток сертификата и не даёт выпустить APK, подписанный не тем ключом.
- Минификация (R8) для release-сборки осознанно выключена: Kotlin-часть — VPN-сервис, плитка быстрых настроек, виджеты — вызывается рефлексией из Tauri и через манифест, где выигрыш в размере исчисляется килобайтами, а риск сломать эти вызовы вполне реален.
- Windows и macOS: в исполняемый файл и инсталляторы добавлены метаданные издателя — издатель, копирайт, домашняя страница, описание. Раньше эти поля были пустыми, что ухудшало репутацию неподписанной сборки у SmartScreen и антивирусов.
- README переведён на английский (`README.en.md`) с переключением языков; добавлены бейджи и раздел о подписи кода.

## Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; система может показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
