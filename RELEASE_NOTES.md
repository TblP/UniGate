# UniGate 1.0.4 — теперь и на Android

Один аккуратный клиент для подключения на компьютере и телефоне.

### Что нового

- Нативный Android VPN на базе sing-box/libbox.
- Полный TUN-туннель, обход RU-трафика и локальной сети.
- Маршрутизация по приложениям с удобным выбором по именам и иконкам.
- Быстрые действия по долгому нажатию на иконку.
- Плитка UniGate в шторке Android.
- Виджеты `Compact 1×1` и `2×2` с состояниями «выключено / подключение / подключено».
- Обновлённая мобильная версия интерфейса UniGate.

### Установка

Сборки проекта не имеют доверенной подписи издателя:

- **Android:** разрешите установку из неизвестного источника; Play Protect или HyperOS могут показать предупреждение.
- **Windows:** SmartScreen — «Подробнее → Выполнить в любом случае».
- **macOS:** после установки выполните
  `sudo xattr -dr com.apple.quarantine /Applications/UniGate.app`

> Android APK предназначен для устройств ARM64.
